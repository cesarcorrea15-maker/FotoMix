# Fotoimpression

## Descripción
Fotoimpression es una aplicación moderna y accesible para la composición de fotos. Permite cargar imágenes, ajustar configuraciones como tamaño, opacidad y rotación, y exportar composiciones en formatos JPEG y PNG.

## Estructura del Proyecto
- **html/**: Contiene los archivos HTML.
- **css/**: Contiene los estilos CSS.
- **js/**: Contiene los scripts JavaScript.
- **MEJORAS_SEGURIDAD.md**: Documentación sobre mejoras de seguridad implementadas.

## Uso
1. Abre el archivo `html/compositor.html` en un navegador.
2. Carga imágenes y ajusta las configuraciones según tus necesidades.
3. Exporta la composición final en el formato deseado.

## Tecnologías Utilizadas
- HTML5
- CSS3
- JavaScript ES6+
- Bootstrap 5.3.3
